# nOrder (Static HTML/CSS/JavaScript)

This project now runs as a plain static web app.

## Files in use

- `index.html`
- `app.css`
- `app.js`

## Run locally

You can open `index.html` directly in a browser, or serve the folder with a simple static server.

Example with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
